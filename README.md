# 历史人格镜像（History Mirror）

> 千百年前，也许有人走过与你相似的人生。

一个面向大众的中国古代历史人物人格镜像测试。用户通过 18 道情境选择题，在 24 位中国古代历史人物中寻找最接近的“历史人格镜像”，并获得性格结构、关键选择、同龄人生阶段映射、力量与阴影、命运分叉及参考建议。

## 当前版本

**Beta 1.2**

当前版本为可进行真人内测的单页 Web/H5 原型：

- 18 关固定用户体验
- 前 14 关估计宽人格 / 决策结构
- 第 15–18 关逐题自适应定局
- 24 位中国古代历史人物候选池
- 14 关后保留 Top 6，再通过动态题更新排序
- 输出 1 名主镜像 + 2 名近邻
- 不展示未经真人常模校准的百分比相似度
- 支持“高重合 / 近邻 / 交界型”结果表达
- 支持回退修改答案
- 包含同龄史镜 / 人生阶段镜像
- 支持结果反馈、匿名内测记录导出与分享卡生成
- 测试运行不依赖 AI API

## 产品原则

这个项目不是学术心理量表，也不声称能够判断真实“前世”。“宿命感”是一种叙事体验，底层匹配则尽量建立在可解释的人格、价值、决策和压力反应逻辑之上。

核心原则包括：

- 题目以有真实代价的情境选择为主，避免明显的“好答案 / 坏答案”
- 性别不参与核心人格匹配；年龄主要用于人生阶段映射
- 历史人物匹配由确定性规则引擎完成，不由大模型临场决定
- AI 可参与研发和内容制作，但 Beta 版本运行时不调用模型
- 历史事实层与产品解释层分离
- 不虚构用户的具体人生经历
- 不把争议历史人物视觉丑化或道德脸谱化
- 当人物池中没有足够接近的角色时，允许输出“交界型”结果，而不是强行宣称高度相似

## 仓库结构

- `index.html`：Web / GitHub Pages 入口。负责恢复并启动完整 Beta 1.2。
- `archive/`：Beta 1.2 原始单 HTML 的 gzip + Base64 无损归档分片。入口只按顺序读取并解压，不改写测试逻辑、题目或结果内容。
- `VERSION.md`：当前版本说明。
- `README.md`：产品与仓库说明。

之所以保留归档形式，是为了先把当前已经验收的 **Beta 1.2 单文件版本原样固化**，避免为了仓库拆分而引入新的功能差异。后续正式开发版本可再把题库、人物数据、样式与算法拆为可维护源码目录。

## 技术形态

目前产品以 **Mobile-first 单页 Web/H5** 为核心：

- HTML / CSS / JavaScript
- 无需账号即可完成测试
- 无 AI API 依赖
- 可作为静态站点部署
- 适合 GitHub Pages、Cloudflare Pages 等静态托管

仓库根目录的 `index.html` 即部署入口。现代 Safari、Chrome、Edge 可直接使用浏览器原生 gzip 解压能力载入归档。

> 注：人物画像在 Beta 1.2 中仍使用外部历史图像地址，因此图片显示仍受网络环境影响。正式公开版应把最终确认的 24 张人物视觉素材自托管或内嵌。

## 状态

当前处于 **Beta 真人内测阶段**。下一步重点是收集真实用户反馈，包括：

- 第一镜像主观认可度
- Top 2 / Top 3 是否经常比 Top 1 更像
- 人物出现分布
- “交界型”比例
- 重复测试稳定性
- 哪些题目存在理解偏差或选项吸附

这些数据将用于后续校准题目、人物向量和候补人物补位。
